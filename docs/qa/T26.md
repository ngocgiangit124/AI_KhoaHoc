## Kiểm thật qua Nginx
- File `vv-common.conf` trong container có `fastcgi_param HTTP_X_INTERNAL_TOKEN ""` / `HTTP_X_CLIENT_IP ""` ở `/index.php` và webhooks; `nginx -t` OK.
- 126 request tới `127.0.0.1:8000` (Host api.localhost) với `X-Internal-Token: x` và `X-Client-IP` khác nhau: 120 x 200 rồi 6 x 429, tức là giới hạn theo IP kết nối.
- Hạn chế: `INTERNAL_API_TOKEN` trong backend/.env đang rỗng nên tính năng tắt, kết quả trên sẽ giống nhau dù Nginx có xoá header hay không. **Chưa kiểm thật** việc Nginx xoá header khi token đúng; chỉ xác minh cấu hình có mặt trong container. Nếu muốn kiểm chắc: đặt token tạm trong môi trường staging và gửi token đúng kèm X-Client-IP khác nhau, kỳ vọng vẫn 429 sau 120.
- Chưa kiểm: file trên đĩa mới hơn lần nạp của Nginx hay không (không có `ps`, không reload); nếu không chắc, PO chạy `nginx -s reload`.
