- Tái hiện: `/quan-tri/nhat-ky`, Tab tới nút "Chi tiết" của một dòng, Enter mở hộp, Esc (hoặc nút Đóng).

Gợi ý: giữ dialog luôn mount với `open={!!selected}` (cần tránh id trùng), hoặc lưu nút kích hoạt bằng ref và `focus()` trong `onClose`.
