### Phát hiện
#### C1 [SHOULD] `release-images.yml`: `git fetch origin main` sẽ lỗi nếu repo private (đã xoá thông tin xác thực)
- Vị trí: `.github/workflows/release-images.yml:58-60`.
- Vấn đề: checkout dùng `persist-credentials: false` nên token bị gỡ khỏi git config sau bước checkout; `git fetch --no-tags origin main` ở bước sau không có thông tin xác thực, repo private sẽ thất bại `could not read Username` (fail đóng nên an toàn nhưng chặn phát hành production lần đầu). Không cần fetch: `fetch-depth: 0` đã kéo toàn bộ `refs/remotes/origin/*`.
- Đề xuất:
  ~~~yaml
  - name: SHA phải nằm trong lịch sử main
    run: |
      if ! git merge-base --is-ancestor "$INPUT_SHA" refs/remotes/origin/main; then
        echo "::error::SHA không thuộc nhánh main"; exit 1
      fi
      [ "$(git rev-parse HEAD)" = "$INPUT_SHA" ] || { echo "::error::checkout không khớp SHA"; exit 1; }
  ~~~

#### C2 [SHOULD] Bước ký chỉ yêu cầu ít nhất một dòng `# ref`, không yêu cầu đủ số image
